# PE-Core Weights

The pretrained PE-Core weights are not included in this archive because they exceed the supplementary material submission size limit.

Please obtain the pretrained PE-Core-L14-336 weights from the official source and place the file at:

```text
models/backbone/pe/weights/PE-Core-L14-336.pt
```

The expected directory structure is:

```text
models/backbone/pe/weights/
├── README.md
└── PE-Core-L14-336.pt
```

This weight file is used when the backbone is set to:

```text
pe_l14_336
```
